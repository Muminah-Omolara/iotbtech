## Getting Started

To get started with the Tektariq project locally, follow these steps:

### 1. Clone the Repository

```bash
git clone https://github.com/iotb-tech/tektariq-website
cd tektariq-website
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the Development Server
```bash
npm run dev
```

### 4. Contributing
- Clone the  repository to your local machine.
```bash
git clone https://github.com/iotb-tech/tektariq-website
cd tektariq-website
```
- Create a new branch for the feature you're working on:
```bash
git checkout -b feature/your-feature-name
```
- Make your changes and commit them:
```bash
git add .
git commit -m "Add a descriptive commit message"
```
- Push your branch
```bash
git push origin feature/your-feature-name
```
- Open a Pull Request (PR) to the dev branch on the main repository.
Ensure your changes are well-tested and follow the project's coding style.

### 5. Branching Strategy
- dev: The main development branch. All new features and bug fixes should be merged here.
- Feature branches: Create a new branch from dev for each new feature or bug fix. Name the branch like feature/your-feature-name or bugfix/issue-name.
- Pull Requests: Always open PRs against the dev branch.
